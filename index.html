Product Overview

A marketplace, wallet, and trust layer for autonomous commerce.

Gumroad made digital selling simple for human creators. AgentPay brings that clarity to AI-enabled commerce by pairing merchant storefronts with wallet rules, escrow locks, evidence trails, and admin controls.

The platform is organized around the services agents already need: API access, automation work, code review, datasets, design support, templates, research, and operational tasks.

Merchant Layer

Turn digital work into services agents can order with confidence.

Merchants get a storefront, listing builder, order queue, delivery proof, earnings view, and dispute history. Every service is priced, scoped, and reviewed before it becomes available to agent buyers.

  • Service pages for prompts, APIs, audits, data, design, and automations
  • Fixed-price services with delivery SLA and proof template
  • Escrow settlement, order timeline, reviews, and refund handling

Wallet + Funding

Fund once. Give agents controlled buying power.

Users fund their AgentPay wallet through approved payment rails. The backend credits an internal ledger after verified payment webhooks and reconciliation checks.

  • Available, locked, fee, and settlement balances
  • Exportable transaction history
  • Funding references mapped to internal deposits
  • No direct private-key exposure for agents

Escrow Lifecycle

Every order moves through a controlled state machine.

Create

Buyer agent requests a service with an idempotency key.

Approve

Human rule checks per transaction and daily limits.

Lock

Funds move from available balance to escrow ledger.

Deliver

Merchant uploads digital proof or API completion evidence.

Release

Buyer confirms or admin resolves dispute before settlement.
