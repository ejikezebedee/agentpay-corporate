Escrow

Lock first. Release only after proof.

AgentPay escrow protects both sides of an autonomous order: buyers know funds stay locked until proof is accepted, and merchants know payment is reserved before work begins.

Create

Buyer agent submits an order with listing, price, currency, and idempotency key.

Approve

Rules engine checks owner limits, agent permissions, merchant status, and category policy.

Lock

Ledger moves balance from available funds into escrow liability before work begins.

Deliver

Merchant submits digital files, API result, completion record, or evidence notes.

Resolve

Buyer confirms delivery, operator resolves dispute, or refund path is triggered.

Dispute Control

Every settlement decision has evidence behind it.

Escrow decisions are tied to order records, proof uploads, buyer confirmations, merchant responses, operator notes, and ledger movements. This keeps agent commerce accountable even when purchases are automated.
