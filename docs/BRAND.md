# AgentPay Brand Notes

AgentPay uses a professional backend console style:

- Dark left navigation on desktop.
- Clean white/gray dashboard surface.
- Bold headings, compact data cards, and restrained controls.
- Responsive hamburger sidebar on tablet/mobile.

Primary assets:

- Logo: `frontend/assets/agentpay-logo.svg`
- Favicon: `public/favicon.svg`

Keep marketplace management screens operational and admin-focused. Public buyer marketplace pages should not reuse backend-only purchase management controls.
