# Pricing And ROI Pack

Use this pack to price AgentPay, explain buyer value, handle discount pressure, and turn the digital product into a higher-value customization or implementation-planning offer.

This document does not promise financial results. It gives sellers and agencies a practical way to explain time savings, scope value, and service packaging.

## Price Positioning

AgentPay is positioned as a productized MVP foundation, not a simple landing-page template.

Core value:

- A buyer gets a polished public website.
- A buyer gets a clickable product console.
- A buyer gets backend starter code and tests.
- A buyer gets API, database, escrow, deployment, launch-control, verification, support, demo, and onboarding documentation.
- A seller or agency gets materials to convert the download into paid customization and implementation-planning work.

## Recommended Price Ladder

### Digital Download

Use for self-serve buyers who want the full package without direct support.

- Launch price: USD 49 to USD 99.
- Standard price: USD 99 to USD 149.
- Best buyer: founder, strategist, developer, or agency testing the concept.

### Download Plus Walkthrough

Use when the buyer wants guidance but not custom implementation.

- Suggested price: USD 199 to USD 399.
- Includes one product walkthrough, setup review, and document orientation.
- Does not include backend production deployment or regulated payment activation.

### Brand Customization Package

Use for agencies or client work where the static frontend and docs need buyer-specific edits.

- Suggested price: USD 499 to USD 1,500.
- Includes brand name, logo, colors, copy edits, static preview, and handoff checklist.
- Excludes production payment processing unless separately scoped.

### Implementation Planning Package

Use when the buyer wants the backend path mapped before building.

- Suggested price: USD 1,500 to USD 5,000.
- Includes architecture review, production backend plan, launch-control gate review, data boundary review, and implementation scope.
- Excludes legal, tax, compliance approval, and live payment credentials.

### Production Build Advisory

Use only when the buyer understands that production work is a separate engagement.

- Suggested price: custom quote.
- Scope depends on payment provider requirements, hosting target, databases, auth, audit logging, reconciliation, privacy, compliance, and launch approvals.

## Discount Rules

Use discounts carefully so the product does not look disposable.

Acceptable discount reasons:

- Launch window.
- Limited-time marketplace promotion.
- Bundle with a paid walkthrough.
- Repeat buyer or agency license discussion.

Avoid:

- Heavy permanent discounts.
- Discounts that include support beyond the written support policy.
- Discounts that imply live-payment readiness.
- Discounts that include implementation work without a written scope.

Suggested maximum self-serve discount:

- 20 percent for a launch or holiday campaign.

Suggested agency bundle discount:

- Discount the download only, not the service hours.

## Price Objection Responses

### It is expensive for a template.

Response:

AgentPay is not only a visual template. It includes the website, product console, backend starter, tests, schemas, OpenAPI contract, escrow rules, deployment bundle, launch controls, verification guide, sales copy, onboarding, demo script, and implementation scope materials.

### Can I get it cheaper?

Response:

The self-serve download is already priced below the cost of building the same planning package from scratch. If budget is tight, start with the download only and add customization later.

### Does this replace developers?

Response:

No. It reduces blank-page planning and gives developers a structured starting point. Production payment systems still need qualified development, security review, compliance review, and launch controls.

### Why pay before the backend is live?

Response:

Most MVPs fail before production because the product story, flows, database boundaries, and launch requirements are unclear. AgentPay helps define those pieces before expensive production work starts.

## Upsell Decision Tree

- Buyer only wants to explore: sell digital download.
- Buyer wants help understanding files: offer walkthrough.
- Buyer wants custom branding: offer customization package.
- Buyer wants client-ready delivery: offer agency package.
- Buyer wants production payments: offer implementation planning first.
- Buyer asks for regulated launch: require legal and compliance review before build scope.

## Pricing Page Notes

When adapting the public pricing page:

- Keep the self-serve starter simple.
- Separate digital product pricing from implementation services.
- State clearly that live payments are excluded until production launch gates are complete.
- Avoid unlimited support promises.
- Link service prices to written scope, acceptance criteria, and change-control rules.
