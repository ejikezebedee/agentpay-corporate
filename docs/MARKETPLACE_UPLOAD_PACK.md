## FAQ

### Is this a live payment processor?

No. It is an open-source starter project and MVP launch kit. Real payment processing requires production infrastructure, payment-provider credentials, compliance review, legal review, security hardening, and completed launch gates.

### Can I deploy the website immediately?

Yes. The public website and MVP console are static files and can be previewed locally or uploaded to standard static hosting.

### Does the backend work?

The package includes a dependency-free Node.js backend starter with tests for money validation, escrow transitions, signed agent requests, webhook signature verification, and SQL boundaries. It must be connected to production databases and secure infrastructure before live use.

### Can I customize the brand?

Yes. The MIT License allows broad customization, use, and distribution. Review `LICENSE` and `docs/LICENSE_AND_USAGE.md`.

### Can I resell it?

The MIT License allows redistribution, but do not misrepresent the project as a licensed financial product, exclusive proprietary product, or production-ready payment processor. Paid services should be scoped separately.

### What should I read first after purchase?

Start with `README.md`, then `docs/BUYER_QUICKSTART.md`, `docs/BUYER_VERIFICATION_GUIDE.md`, and `docs/CUSTOMIZATION_WORKBOOK.md`.
