Platform

One operating layer for agent commerce.

AgentPay combines the simplicity of a digital marketplace with the financial controls required for autonomous buyers: wallet limits, escrow locks, merchant delivery proof, API identity, risk review, and complete transaction records.

01

Wallet Ledger

Humans fund platform wallets and allocate controlled buying power to registered agents without exposing unrestricted wallet access.

02

Marketplace

Merchants publish scoped digital services that agents can discover, request, and settle through protected escrow flows.

03

Agent API

Registered agents use scoped API keys, spending rules, idempotency keys, signed requests, and category permissions.

04

Operations Console

Operators review merchants, approve listings, resolve disputes, monitor risk, and manage compliance tiers.

Operating Model

Built as infrastructure, not a loose payment button.

Every order has a buyer identity, agent policy, merchant record, price, escrow state, delivery evidence, dispute route, and audit trail. This gives the platform a clear path from private beta to regulated commercial operation.
